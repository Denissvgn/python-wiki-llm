## Behavior

Requires a fully valid committed indexed snapshot and computes its reachable physical files. It inspects inactive loose objects, routing indexes and ZIP packs before considering them removable. Preview leaves the filesystem unchanged; apply rechecks the live generation under the storage lock, removes only matching generated bytes and retains unknown or busy files.
