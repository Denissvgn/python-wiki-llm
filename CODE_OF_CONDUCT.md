# Code of Conduct

## Our Standards

LLM Wiki CLI is a developer tool for maintaining project documentation with
coding agents. The project welcomes issue reports, design discussion,
documentation fixes, and code contributions from people with different levels
of experience.

Participants are expected to:

- Be respectful and constructive in discussions.
- Focus critique on the technical work, not on people.
- Assume good intent while still asking for clarity when something is risky or
  ambiguous.
- Keep reports actionable by including relevant context, commands, versions,
  and reproduction steps.
- Respect maintainers' time by keeping comments on topic.

Unacceptable behavior includes harassment, personal attacks, discriminatory
language, sustained off-topic disruption, publishing private information, or
pressuring maintainers to bypass security or safety review.

## Scope

This code of conduct applies to project spaces including GitHub issues, pull
requests, discussions, and any project-maintained communication channel. It also
applies when someone represents the project in a public technical setting.

## Enforcement

Maintainers may edit or remove comments, close discussions, block users, or take
other moderation action when behavior conflicts with these standards.

If you need to report a conduct concern, contact the maintainer listed in
`pyproject.toml`. Include links or screenshots when possible. Reports will be
handled with discretion and reviewed in the context of the project space where
the behavior occurred.

## Attribution

This policy is intentionally short and project-specific. It is inspired by
common open source community standards, but it is not a verbatim copy of a
third-party code of conduct.
